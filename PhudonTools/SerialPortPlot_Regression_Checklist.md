# SerialPortPlot 回归测试清单

## 1. 构建与启动
1. 执行 `qmake STM32IDE.pro`。
2. 执行 `mingw32-make -f Makefile.Release release/STM32IDE.exe`。
3. 启动 `release/STM32IDE.exe`，从工具菜单打开“串口调试助手”。
4. 预期：
   - 无编译错误。
   - 工具窗口可正常打开且可重复打开/激活。

## 2. 会话与标签页
1. 点击 `➕` 增加多个会话。
2. 双击会话标签重命名。
3. 连续关闭会话标签，直到只剩一个真实会话。
4. 预期：
   - `➕` 标签不可被关闭。
   - 最后一个真实会话不会导致整个工具窗口关闭。

## 3. 分屏行为
1. 在任一分屏点击“水平分屏”“垂直分屏”。
2. 在指定分屏点击“关闭分屏”。
3. 预期：
   - 新分屏按当前分屏位置创建。
   - 关闭动作作用于当前触发分屏，不是“最后创建的分屏”。
   - 至少保留一个分屏实例。

## 4. 串口开关与状态
1. 选择可用端口并打开串口。
2. 再次点击关闭串口。
3. 预期：
   - 状态图标、状态栏文字、欢迎文案同步更新。
   - 打开时端口配置被禁用，关闭时恢复可编辑。
   - 自动发送选项在关闭后自动停用。

## 5. 接收显示与日志模式
1. 关闭“日志模式”，接收一帧数据。
2. 打开“日志模式”，再次接收数据。
3. 预期：
   - 非日志模式显示 `[RX]`。
   - 日志模式显示 `[LOG][RX]`，并携带时间戳。

## 6. 单条发送
1. ASCII 模式发送普通文本，观察接收区回显。
2. HEX 模式发送十六进制文本，观察发送字节。
3. 打开“发送新行”再发送。
4. 预期：
   - 接收区显示 `[TX]` 或 `[LOG][TX]`。
   - 新行行为追加 `\r\n`。
   - 历史记录可回填最近发送内容。

## 7. 自动发送
1. 打开串口后勾选“自动发送”，设置较短间隔。
2. 切换到其他标签页再切回来。
3. 关闭串口。
4. 预期：
   - 自动发送持续触发，不受标签页隐藏影响。
   - 关闭串口后自动发送停止并取消勾选。

## 8. 多条发送
1. 在“多条发送”填入多条内容，勾选部分项并发送。
2. 打开“自动循环(ms)”观察循环发送。
3. 勾选“16进制”“发送新行”后再发送。
4. 预期：
   - 仅勾选项被发送。
   - 循环发送按页/序号轮转。
   - ASCII 新行为 `\r\n`。

## 9. 波形与协议解析
1. 勾选“使能波形显示”。
2. 发送多组 `$1 2 3;` 或 `$10 20;` 形式帧。
3. 点击清空接收。
4. 预期：
   - 能动态创建通道并持续绘图。
   - 波形缓冲按帧解析，不因跨包拆分异常。
   - 清空后图形数据、接收缓冲、滚动条位置全部复位。

## 10. 时间单位与主题
1. 切换 X 轴时间单位（Points/ms/s）。
2. 切换波形主题与全局主题。
3. 预期：
   - 时间单位不仅标题变化，刻度标签也按单位变化（s 模式缩放显示）。
   - 主题切换对当前及历史分屏生效，无崩溃。

## 11. 导入导出
1. 导出多条发送 CSV。
2. 清空并重新导入 CSV。
3. 预期：
   - 页数、勾选状态、内容可恢复。
   - 包含逗号的内容不丢失（从第 5 列起拼接）。

## 12. 稳定性
1. 长时间高频接收（建议 > 5 分钟）。
2. 同时操作：切主题、开关波形、分屏、发送。
3. 预期：
   - 无 UI 卡死/崩溃。
   - 接收区不会无上限膨胀。
   - 串口资源错误时可弹窗并安全收口。
