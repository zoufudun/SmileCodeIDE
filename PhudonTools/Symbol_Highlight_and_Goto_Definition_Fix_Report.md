# 符号同名高亮与全工程跨文件转定义故障分析与修复报告

## 1. 问题概述
在编辑器使用过程中，存在以下两个核心体验问题：
1. **符号同名高亮（Occurrence Highlighting）**：光标选中或停留在变量、函数、宏等符号上时，当前行或全文没有出现明显的高亮框，或者特定符号（如宏定义）无法被高亮，同时伴有轻微输入卡顿。
2. **全工程跨文件转定义（Jump to Definition - F12）**：按 F12 转定义时经常无反应、找不到宏定义、找不到头文件内联实现，或者跳转坐标偏离目标符号位置。

---

## 2. 根因深度剖析

### 2.1 符号同名高亮故障根因
1. **预处理指令被整体清洗（Masking Bug）**：
   `generateCleanCppCode()` 在预处理阶段将所有 `#` 开头的行全部用空格覆盖，导致 `#define` 宏符号在搜索文本中直接消失，无论是高亮宏还是在宏定义处高亮均失败。
2. **Scintilla 指示器渲染层级遮挡（DrawUnder Bug）**：
   高亮指示器 `OCCURRENCE_INDICATOR (28)` 配置了 `setIndicatorDrawUnder(true)`，指示器被绘制在文本最底层。而编辑器启用了当前行背景高亮（Caret Line Background），导致当前光标所在行的指示器被不透明背景色完全覆盖，视觉上不可见。
3. **算法在内层循环执行全量字符串切片与统计（$O(N^2)$ 性能瓶颈）**：
   在遍历符号引用时，每次匹配都调用 `code.left(absOffset).count('\n')`，对几千行代码的大文件产生了数百次大块内存分配与扫描，导致主线程响应迟缓、高亮防抖定时器异常。
4. **Scintilla 延迟着色与样式掩码判断漏洞**：
   光标位于词尾时 `SCI_GETCURRENTPOS` 获得的是后一个字符的 Style，且未经过 `style & 0x3F` 掩码过滤，易受 Inactive 样式影响。

### 2.2 全工程跨文件转定义故障根因
1. **宏定义规则在清洗后的文本中永远无法命中**：
   跨文件扫描在 `cleanCode` 上执行 `#[ \t]*define` 正则，但 `cleanCode` 已被擦除所有 `#` 行，全工程宏跳转 100% 失败。
2. **头文件函数实现被硬编码跳过**：
   普通函数规则 `funcImplRe` 被添加了 `if (!isHeader)` 条件，写在 `.h`/`.hpp` 中的内联函数（`inline`）、模板函数以及单头文件库实现全部被跳过。
3. **类名作用域提取在 `.cpp` 中失效**：
   `extractEnclosingClassName` 仅向上查找 `class` 关键字，在只有 `ClassName::Method()` 的 `.cpp` 实现文件中永远返回空，导致评分权重无法命中。
4. **使用模糊 `indexOf` 导致跳转坐标偏移**：
   在正则匹配后使用 `fCode.indexOf(symbolName, matchStart)`，当符号为短词（如 `init`、`data`）且前面包含类名或返回值（如 `DataHandler::init`）时，会误匹配到前面的子串，导致跳转行列号严重偏移。
5. **函数参数正则遇到复杂语法断裂**：
   使用 `\([^;)]*\)` 匹配参数列表，遇到带括号的参数默认值或函数指针参数时匹配失败。
6. **定义行未阻断导致向全工程穿透**：
   当光标已经处于局部变量定义行时，按 F12 会穿透到全工程去搜索同名全局变量，跳至其他文件。

---

## 3. 系统性修复实施方案

1. **重构预处理清洗 `generateCleanCppCode`**：保留 `#define` 宏定义语句，仅屏蔽 `#include`、`#pragma` 等非定义指令。
2. **修正指示器渲染与图层**：`setIndicatorDrawUnder(false)`，调整轮廓透明度（OutlineAlpha 255，FillAlpha 70），使用 Scintilla 原生消息 `SCI_INDICATORCLEARRANGE` 全文范围清空。
3. **算法降阶至 $O(N)$**：预建 `lineStarts` 偏移表，通过二分查找 `std::upper_bound` 实现微秒级行号列号换算。
4. **全面开放头文件实现检索**：移除 `if (!isHeader)` 限制，支持头文件内联与模板实现跳转。
5. **精准捕获组坐标定位**：废除危险的 `indexOf`，直接使用正则捕获组 `m.capturedStart(...)` 定位字符偏移。
6. **智能推导 `.cpp` 类名上下文**：支持从当前函数签名 `ClassName::Method` 反向提取当前类名。
7. **修复定义行自身阻断**：在局部变量或形参定义行按 F12 时平滑选中当前定义，不再向全工程穿透误跳。
