# 独立多通信接口数字示波器开发与集成完成

## 1. 升级功能概述
根据最新需求，已将示波器从串口调试助手中完全独立出来，打造为**独立多通信接口专业数字示波器（Standalone Multi-Interface Digital Oscilloscope）**，并在主界面顶部菜单栏和“调试工具”工具栏中提供一键快速启动入口。

---

### 2. 独立示波器核心技术架构与特性

#### (1) 多通信接口与硬件协议全面支持
示波器左侧配备专门的 **“📡 通信接口配置”** 面板，支持 5 大通信类别，覆盖几乎所有工业与嵌入式场景：
1. **RS232 / RS485 串口**：
   - 端口选择、波特率（1200 ~ 921600+）、数据位、校验位、停止位与流控设置。
2. **Modbus RTU / Modbus TCP 工业协议**：
   - 从机站号（1~247）、功能码（01/02/03/04）、起始寄存器地址、寄存器数量（1~32）、轮询周期（10~5000ms）；
   - 支持 16 位有符号/无符号整数、32 位单精度浮点数（ABCD / CDAB 字节序解析）。
3. **CAN / CAN FD 总线**：
   - 支持创芯科技 ControlCAN (USBCAN-2C / 2I / 2U 等)、致远电子 ZLG USBCAN-FD 系列及虚拟测试设备；
   - 支持 CAN 2.0 / CAN FD、指定设备索引、通道索引、50K~1Mbps 波特率选择；
   - 自动将 CAN 报文字段解构映射为实时多通道波形。
4. **以太网 (Ethernet TCP / UDP)**：
   - 支持 TCP Client（主动连接目标 IP/端口）、TCP Server（本地监听端口等待设备连接）、UDP 单播/广播接收。
5. **虚拟内置多波形信号发生器 (Virtual Signal Generator)**：
   - 正弦波、方波、三角波、锯齿波、白噪声、扫频信号；
   - 支持频率 (0.1~1000Hz)、幅度 (0.1~500V)、直流偏置、相位及信噪比/高斯噪声叠加调节，脱离物理硬件亦可进行算法验证。

---

#### (2) 16 通道高性能波形引擎与测量系统
1. **16 路独立通道矩阵**：
   - 各通道独立开启/隐藏、名称重命名、调色板颜色拾取、垂直比例（V/div）、偏置电压（V）、实时电压监测；
   - 支持 16 种工业标准配色方案与曲线平滑着色。
2. **时基与触发系统**：
   - 水平分度时基：100μs/div ~ 10s/div，支持自动滚动模式（Roll / Strip Chart）与单帧捕获；
   - 触发模式：自动 (Auto) / 普通 (Normal) / 单次 (Single)；
   - 触发源（CH1~CH16）、边沿类型（上升沿/下降沿）、触发电平微调与荧光指示线。
3. **双游标测量 (Cursor A & B)**：
   - 双垂直测量游标，支持鼠标实时拖动或数值输入；
   - 实时计算输出 $\Delta T$（时间差）、$1/\Delta T$（等效频率）、$\Delta V$（通道电压差）。
4. **实时硬件参数测量表**：
   - 峰峰值 ($V_{pp}$)、最大值 ($V_{max}$)、最小值 ($V_{min}$)、平均值 ($V_{avg}$)、有效值 ($V_{rms}$)、主频 ($Freq$)。
5. **FFT 频谱分析仪**：
   - 支持实时快速傅里叶变换，显示信号谐波分布与频域能量图谱。
6. **数据与报表导出**：
   - 支持将当前 16 通道采样数据导出为标准 CSV 电子表格；
   - 支持一键导出高清 PNG 波形图片及 PDF 测量报告。
