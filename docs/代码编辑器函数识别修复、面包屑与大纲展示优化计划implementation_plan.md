## 根因分析与设计方案

### 1. 图 1 函数识别 Bug 分析与修复
- **原因分析**：在旧版 `parseFunctions` 中，预处理指令（如 `#include <stdint.h>`）没有分号或大括号结尾，扫描器在遇到下一行 `int main(void) {` 的左大括号 `{` 之前，未重置语句起始位置 `stmtStart`。导致 `beforeParen` 将 `#include <stdint.h>\n\nint main` 全部吞入，并将 `#include <stdint.h>` 误当作 `main` 函数的返回类型。
- **修复方案**：
  1. 在语句切分阶段，对以 `#` 开头的预处理指令行进行边界隔离，预处理行以换行符 `\n` 为结束边界，更新 `stmtStart`，确保预处理行绝不污染后续函数声明；
  2. 增强 `retType` 提取逻辑：从函数名前截取类型时，仅取语句在同一行或紧邻的有效类型 Token（如 `int`、`void`、`uint8_t *` 等），自动过滤多余修饰符与多行干扰，精确提取返回类型。

### 2. 面包屑导航栏与同目录文件快速切换（对齐图 2、图 3）
- **路径与文件图标**：
  - 显示上级目录路径（如 `PhudonTools >` 或 `User > sdmmc >`）；
  - 文件名前添加青色 `C` / `C++` / `H` 文件类型标识（图 2 图 3 样式）；
- **点击文件遍历同目录**：
  - 将面包屑中的文件名实现为带悬浮/点击效果的 `QToolButton`；
  - 点击时扫描当前文件所在目录下的所有 `.c`、`.cpp`、`.cc`、`.cxx`、`.h`、`.hpp` 文件；
  - 弹出定制样式的下拉菜单，显示文件列表并高亮当前文件，点击直接通过 `openFile(...)` 切换加载。

### 3. 大纲展示规范与类成员层级树（对齐图 3，支持收缩/展开）
- **控件升级**：
  - 将侧边栏大纲控件从 `QListWidget` 升级为 `QTreeWidget`（隐藏表头、配置层级缩进与展开动画）；
- **层级解析与组织**：
  - 在 `.h` / `.hpp` 头文件中声明的 `class` / `struct` 作为顶级节点（一级），其内部的成员方法、成员变量作为子节点（二级）；
  - 在 `.cpp` 源文件中实现的 `ClassName::MethodName`，自动按 `ClassName` 分组作为顶级节点，方法作为二级子节点挂载；
  - 全局/静态函数（如 `Wait_SDCARD_Ready`、`BSP_SD_Init`）和全局变量（如 `uSdHandle`）作为顶级节点；
  - 默认全部展开，用户可随时点击箭头收缩/展开；
- **展示格式（1:1 对齐图 3）**：
  - 函数节点：`[紫色 3D 棱箱图标] 函数名 返回类型 (参数列表)`（如 `BSP_SD_ReadBlocks int (int *, int, int)`）；
  - 变量节点：`[青色图标] 变量名 类型`（如 `uSdHandle int`）；
  - 右侧显示当前文件内的引用频次徽标（如 `+9`、`1`、`2`）；
  - 自定义 `SymbolTreeDelegate` 实现字体样式、颜色及交互选中高亮。
