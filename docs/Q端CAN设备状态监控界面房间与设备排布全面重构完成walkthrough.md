# Q端CAN设备状态监控界面房间与设备排布全面重构完成

本次针对 Q端 CAN 设备状态监控界面的房间布局、设备图标网格排布、自动扩容与未摆放区域管理进行了推倒重来的全面重构。

---

## 核心实现与功能清单

### 1. 房间按设备数量自动自适应扩容
- **规整网格计算**：根据房间内关联的设备总数 $N$ 自适应计算最优行列：
  - $N \le 2$：1 行 1~2 列
  - $N \in [3, 4]$：2 行 2 列
  - $N \in [5, 6]$：2 行 3 列
  - $N \in [7, 8]$：2 行 4 列
  - $N > 8$：$\lceil N / 4 \rceil$ 行 4 列
- **精准尺寸包围盒**：
  - 宽度：$\text{reqW} = \text{PAD\_LEFT}(20) + \text{PAD\_RIGHT}(20) + cols \times \text{CARD\_W}(96) + (cols-1) \times \text{GAP\_X}(20)$
  - 高度：$\text{reqH} = \text{PAD\_TOP}(52) + \text{PAD\_BOTTOM}(20) + rows \times \text{CARD\_H}(106) + (rows-1) \times \text{GAP\_Y}(20)$
- 房间几何高度与宽度自动保证 $\ge \text{reqW}$ 且 $\ge \text{reqH}$，彻底消除了第 2 行设备溢出房间边框、导致卡片与虚线底边交合重叠的缺陷。

### 2. 严禁设备重叠、房间重叠
- **房间内设备**：采用精确的行列偏移矩阵分配：
  - $X = \text{roomX} + 20 + col \times 116$
  - $Y = \text{roomY} + 52 + row \times 126$
  - 设备间水平与垂直间距严格为 20px，数学上绝无重叠可能。
- **房间之间**：
  - `resolveRoomOverlaps()` 实现流式防重叠算法，保持房间与房间之间水平 40px、垂直 40px 间隙，多行多列整齐排列。

### 3. 严禁设备与房间交合
- 设备卡片起始 Y 严格从 $52\text{px}$ 开始，留出顶部 22px 标题栏、改名/锁定/删除按钮与设备计数器；
- 四周留出充足的 20px 安全内边距，卡片 100% 包含于房间内部。

### 4. 严禁野图标（清除孤立图标）
- 只有属于当前界面且所属房间有效存在的设备才被允许在画布上显示；
- 所属房间为空的设备一律清除画布坐标，绝不出现在房间外面的空白画布上。

### 5. 严格按所属房间属性放置与未摆放区流转
- 所属房间非空的设备严格放入对应名称的房间；
- 所属房间为空的设备统一收纳并展示在底部的【未摆放设备停靠区（Unplaced Dock）】中；
- 拖拽设备进入房间时，自动归属该房间并触发房间自适应扩容；拖出房间时自动退回未摆放区并自动缩减/自适应房间尺寸。

### 6. 默认全量显示所有存在的房间
- 所有从配置加载或新创建的房间 `visible` 默认置为 `true`；
- 切换界面标签页时，属于当前界面的所有房间均默认可见显示；
- 副屏多屏联动（`SubMonitorWindow`）同步应用该套排布与扩容引擎。
