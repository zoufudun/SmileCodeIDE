# 全站导航栏增加首页入口与非文档页主题切换失效物理根治

## 1. 问题概述与用户反馈

在审阅 `v2.3.7` 版本官网时，用户提出了两项关键指令：
1. **图 1 导航栏增加“首页”入口**：在顶部导航栏中央导航区（原为：`产品 ▾`、`容器市场`、`技术文档`、`软件下载`）的最左侧增加【**首页**】入口，方便用户在任意页面（下载页、文档页、各插件详情页）一键返回首页；
2. **彻底解决点击主题切换无效的问题（“只有在文档页面才能切换主题”）**：用户实测发现，目前只有在技术文档页（[`website/docs.html`](file:///k:/TOPFIRE/SmileCodeIDEUpdate/website/docs.html)）点击右上角主题切换按钮才能正常切换主题，而在首页（[`website/index.html`](file:///k:/TOPFIRE/SmileCodeIDEUpdate/website/index.html)）、软件下载页（[`website/download.html`](file:///k:/TOPFIRE/SmileCodeIDEUpdate/website/download.html)）及全部 14 个插件详情页（[`website/plugins/*.html`](file:///k:/TOPFIRE/SmileCodeIDEUpdate/website/plugins/)）点击主题切换按钮均无反应。

---

## 2. 物理级根因定位（为什么“只有在文档页面才能切换主题”？）

通过逐行比对 [`website/docs.html`](file:///k:/TOPFIRE/SmileCodeIDEUpdate/website/docs.html) 与 [`website/index.html`](file:///k:/TOPFIRE/SmileCodeIDEUpdate/website/index.html)、[`website/download.html`](file:///k:/TOPFIRE/SmileCodeIDEUpdate/website/download.html)、[`website/app.js`](file:///k:/TOPFIRE/SmileCodeIDEUpdate/website/app.js) 的事件调用链与 DOM 类名状态，查明了三大精确物理根因：

### 2.1 根因一：`index.html` 与 `plugins/*.html` 存在双重监听器相互抵消（Double-Toggle Cancellation）
- 在 [`website/index.html`](file:///k:/TOPFIRE/SmileCodeIDEUpdate/website/index.html) 和全部 14 个 [`website/plugins/*.html`](file:///k:/TOPFIRE/SmileCodeIDEUpdate/website/plugins/) 中，`#themeToggleBtn` 按钮绑定了内联属性：
  ```html
  <button id="themeToggleBtn" onclick="window.toggleGlobalTheme && window.toggleGlobalTheme()">
  ```
- 与此同时，这些页面底部均引入了 [`website/app.js`](file:///k:/TOPFIRE/SmileCodeIDEUpdate/website/app.js)，而在 `app.js` 第 31–38 行又注册了一次 DOM 点击事件监听：
  ```javascript
  if (themeBtn) {
    themeBtn.addEventListener('click', (e) => {
      const current = document.documentElement.getAttribute('data-theme') || ...;
      const nextTheme = (current === 'dark') ? 'parchment' : 'dark';
      applyWebsiteTheme(nextTheme);
    });
  }
  ```
- **触发过程**：当用户在首页或插件页点击一次按钮时：
  1. 内联 `onclick` (`window.toggleGlobalTheme`) 先执行，将 `data-theme` 从 `parchment` 切换为 `dark`；
  2. 同一事件周期内，`app.js` 的 `addEventListener('click')` 紧接着执行，读取到刚刚变为 `dark` 的 `data-theme`，立即将其反转回 `parchment`！
  3. 两次切换在 0 毫秒内完美相互抵消！而 `docs.html` 没有引入 `app.js`，所以只有 `docs.html` 能正常切换！

### 2.2 根因二：`window.toggleGlobalTheme` 漏更新 `<html>` 节点的 `classList`
- 页面 `<head>` 初始化脚本将 `parchment-theme` / `dark-theme` 类添加到了 `document.documentElement`（即 `<html>` 标签）上；
- 但旧版 `window.toggleGlobalTheme` 在点击切换时只更新了 `document.body.classList`，**未同步移除和更新 `document.documentElement.classList`**；
- 导致 [`website/studio-simulator.css`](file:///k:/TOPFIRE/SmileCodeIDEUpdate/website/studio-simulator.css) 中形如 `.parchment-theme .studio-real-chassis` 的选择器始终匹配 `<html class="parchment-theme">`，使仿真工作台等组件无法随点击变色。

### 2.3 根因三：`download.html` 的 `<body class="parchment-theme">` 在加载时未同步更新
- `<head>` 中的脚本执行时 `document.body` 尚未创建；当浏览器解析到 `<body class="parchment-theme">` 时，写死的 `parchment-theme` 类覆盖了 `<html>` 上的暗色变量；
- `docs.html` 在底部脚本中显式调用了 `applyDocsTheme` 更新了 `document.body.classList`，而 `download.html` 缺少对 `document.body.classList` 的初始化同步。

## 3. 具体修改措施

### 3.1 全站 17 个页面导航栏统一增加【首页】入口
在 [`website/index.html`](file:///k:/TOPFIRE/SmileCodeIDEUpdate/website/index.html)、[`website/docs.html`](file:///k:/TOPFIRE/SmileCodeIDEUpdate/website/docs.html)、[`website/download.html`](file:///k:/TOPFIRE/SmileCodeIDEUpdate/website/download.html) 及全部 14 个 [`website/plugins/*.html`](file:///k:/TOPFIRE/SmileCodeIDEUpdate/website/plugins/) 的 `.nav-links` 最左侧新增【**首页**】导航项，全站导航栏严格统一为：
- **首页** | **产品 ▾** | **容器市场** | **技术文档** | **软件下载**
- 当前所在页面自动高亮 `.active` 状态（首页高亮“首页”，文档页高亮“技术文档”，下载页高亮“软件下载”）。

### 3.2 彻底重构全局唯一主题引擎（消除双重触发与 DOM 不同步）
1. **移除 [`website/app.js`](file:///k:/TOPFIRE/SmileCodeIDEUpdate/website/app.js) 中的重复 `click` 监听器**：
   删除 `app.js` 中对 `themeBtn.addEventListener('click', ...)` 的重复绑定，统一由全局 `window.toggleGlobalTheme(event)` 处理点击事件，并在 `window.toggleGlobalTheme` 内部增加 `200ms` 时间戳防抖锁（`window._lastThemeToggleTime`），从物理机制上杜绝单次点击触发两次反转。
2. **统一 `window.applyGlobalTheme(theme)` 全节点同步**：
   每次初始化或点击切换时，同时同步：
   - `localStorage`（`smilecode_theme` 与 `smilecode-theme`）；
   - `document.documentElement`（`<html>`）的 `data-theme` 属性与 `dark-theme` / `parchment-theme` 类名；
   - `document.body`（`<body>`）的 `data-theme` 属性与 `dark-theme` / `parchment-theme` 类名；
   - `#themeToggleIcon` 太阳/月亮矢量 SVG 图标与 `#studioThemeSelect` 仿真器主题下拉框。
3. **在 `<body>` 起始处与 `DOMContentLoaded` 双重注入初始化同步**：
   确保无论在首页、文档页、下载页还是任意插件页，页面打开瞬间与点击切换瞬间，`<html>` 与 `<body>` 的主题状态 100% 一致。
4. **全站静态资源防缓存版本号升级为 `?v=2.3.8`**：
   将全站所有 HTML 引用的 `style.css?v=2.3.8`、`studio-simulator.css?v=2.3.8`、`app.js?v=2.3.8` 统一追加版本参数，确保浏览器立即加载最新脚本与样式。
