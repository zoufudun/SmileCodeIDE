# SmileCodeIDE v2.2.0 编译、调试、烧写增强总结

日期：2026-10-28。基于用户确认的范围，沿用原生控制器与现有 STM32 核心引擎，完成工作流、图标及版本统一。本次只保留本地 Git 提交和 v2.2.0 标签，不推送远程。

## 主要修改

### 编译与任务控制

- 主窗口创建自己的 STM32DebugController，修复原来只有空单例指针的问题。
- 新增重建、取消当前任务入口；清理进入统一 Building 状态。编译、烧写和调试互斥，启动失败恢复空闲。
- 重复设置相同项目不再重置任务状态；切换、关闭项目和析构时先停止当前任务。烧写取消等待子进程退出，避免下一任务与旧进程重叠。

### 调试和烧写

- 调试停止增加重入保护，避免 GDB 同步结束信号递归调用 stopDebug。防止端口探活和服务就绪信号重复启动 GDB 客户端。
- 新增暂停调试，单步与继续仅在停机后启用。仅查找当前芯片对应的 ELF，使用 `main` 临时函数断点。
- 烧写输出与完成信号在构造阶段连接一次，完整保留启动前错误和日志，多次烧写不会重复连接。
- 统一解析 J-Link、ST-Link、CMSIS-DAP；补齐主 IDE 的 CMSIS-DAP 选择和 OpenOCD 接口参数；烧写地址使用芯片档案中的 Flash 起始地址。
- 工程配置加载不再边读边覆盖文件，恢复芯片与探针后同步界面；清空/切换断点时同步移除编辑器标记。
- 补齐 QScintilla 共享库导入宏，解决运行时信号连接失败，验证边距点击到断点控制器的联动。

### 图标和版本

- 用 Qt QIconEngine / QPainter 绘制明确的锤子、重建、清理、芯片下载、调试虫、停止、暂停、继续、单步和断点图标。菜单、工具栏和主按钮统一使用同一图标来源。
- 正常态采用操作区分色，禁用态统一灰色；已生成深色、浅色背景和禁用态图标预览，以及主窗口截图。
- qmake `VERSION = 2.2.0` 作为版本来源，应用元数据、IDE 应用卡及关于窗口共用版本；Windows 文件/产品版本为 `2.2.0.0`。
- 去除检查更新中的模拟进度与虚假“已是最新版本”提示，显示实际本地版本及未配置在线更新服务的状态。

## 验证记录

验证环境：Windows 11、Qt 6.11.2、Qt 配套 MinGW 13.1.0。初次使用系统默认 MinGW 14 链接失败，切换至 Qt 配套工具链后完成 Release 构建。

控制器测试以当前测试程序模拟有限时长的 make / J-Link 子进程，覆盖任务互斥、实际进程取消和项目切换；不会调用真实烧写器。主窗口测试使用隔离的临时设置和离屏 Qt 平台。

| Qt 测试程序 | 通过 | 失败 |
| --- | ---: | ---: |
| STM32DebugControllerTest | 14 | 0 |
| MainWindowWorkflowTest | 4 | 0 |
| BuildLogModelTest | 18 | 0 |
| FlashLogModelTest | 38 | 0 |
| ProbeDetectorTest | 28 | 0 |
| 合计（含各测试程序初始化、清理） | 102 | 0 |

首轮 5 项控制器回归在原代码上全部失败，修复后通过；新增边距断点回归先复现 `0 != 1`，补齐动态库导入宏后通过，原先 12 条 QScintilla 信号连接警告消失。分栏回归验证非活动编辑器的断点标记保留及清空。主程序最终 Release 构建与 Windows 文件版本检查通过。

图标预览：`build/workflow-icons.png`。主窗口截图：`build/workflow-window.png`。构建日志和测试回执保存在 `build/` 下，不进入版本控制。
