# 设备状态监控界面房间拖拽对齐、多界面显示及设备图标包容性优化计划

## 背景与目标
在 Qt 端设备状态监控界面（`DeviceMonitorPanel`、`RoomWidget`、`DeviceStatusWidget` 等）中，针对用户提出的三大核心问题进行系统性架构修正：
1. **房间自由拖动与后台自动对齐/间距控制**：支持手动拖动房间灵活排布位置，松开后由后台自动执行智能吸附对齐（网格与临近房间边缘吸附）与防重叠间距控制（保证横向 `ROOM_GAP_X` 与纵向 `ROOM_GAP_Y` 间距），同时房间内的设备图标同步随房间平移并保持内部整齐。
2. **多界面（首部/尾部界面）房间显示问题彻底修复**：解决切换界面时“首部界面全显示切换到尾部界面前几个房间丢失，在尾部界面全显示后切换回首部前几个房间又丢失”的严重 BUG。根因是房间 ID 重复导致 `m_roomWidgets` 哈希冲突、多界面房间过滤与管理对话框合并时的覆盖逻辑缺陷。
3. **设备图标未完全包含于房间内部的底层逻辑彻底修正**：彻底排查并修正设备卡片尺寸（`CARD_W=96, CARD_H=106`）、房间内边距（`PAD_TOP=46, PAD_LEFT=16, PAD_RIGHT=16, PAD_BOTTOM=16`）、房间容量自适应计算、房间缩放最小尺寸约束、设备拖拽/摆放位置刚性边界约束。

---

## User Review Required
> [!IMPORTANT]
> 1. 原来在每次调用 `rebuildRoomCanvas()` 时都会强制调用 `autoArrangeRoomDevices()` 将所有房间重置为 `(50, 50)` 的固定流式网格，导致用户手动拖拽摆放的房间位置瞬间被重置覆盖。
> 2. 本次优化后，**手动拖动的房间位置会被持久化保留**，并由后台自动进行吸附对齐与非重叠防碰撞间距调整；原有的“一键自动排布”按钮仍可供用户在需要时一键格式化所有房间。

## 拟定修改方案

### 1. 房间拖动、对齐与间距控制底层逻辑 (`devicemonitorpanel.cpp`, `devicemonitorpanel.h`, `roomwidget.cpp`)
- **房间拖动事件处理 (`onRoomMoved`)**：
  - 计算未缩放的基础几何位置 `unzoomedNewGeom`。
  - **智能吸附对齐**：
    - 网格吸附：对齐到标准步长（10px / 20px）。
    - 临近房间吸附：当拖动房间的 Left/Top/Right/Bottom 与同界面其他房间的边缘或标准间距位（`other.right + ROOM_GAP_X` 等）接近时自动吸附对齐。
  - **间距与防碰撞控制**：
    - 遍历同界面其他房间，若与当前拖动房间发生重叠或水平/垂直间距小于 `ROOM_GAP_X=36` / `ROOM_GAP_Y=36`，自动平移避让邻近房间，确保房间之间间隙均匀且不交合。
    - 当邻近房间平移时，同步平移其内部的所有设备卡片坐标。
  - **内部设备同步与边界包容**：
    - 被拖动房间内部的设备卡片随房间移动量 $(\Delta x, \Delta y)$ 同步平移。
    - 检查并刚性约束该房间内部所有设备坐标，确保全部严格位于房间内容区内。
  - **持久化与画布刷新**：
    - 保存房间布局配置，重绘画布时不重置房间基础坐标。

### 2. 多界面房间唯一 ID 与显示切换彻底修复 (`devicemonitorpanel.cpp`, `roommanagerdialog.cpp`, `roommanagerdialog.h`)
- **全局唯一 Room ID 生成与清洗**：
  - 引入 `generateUniqueRoomId(targetView)` 生成基于 UUID 或唯一序列号的房间 ID，彻底消除不同界面之间房间 ID 冲突（如同时存在 `room_1`）。
  - 在 `loadRoomLayout()`、`m_rooms` 初始化及导入时，对重复 ID 自动执行唯一化清洗。
- **界面切换与 `m_roomWidgets` 复用机制修正**：
  - 在 `rebuildRoomCanvas()` 中，`normalizeViewName(r.targetView) == activeViewName` 的房间确保创建/显示对应的 `RoomWidget`；属于其他界面的房间执行 `hide()`。
  - 杜绝因 ID 相同导致视图 A 的控件在遍历视图 B 时被错误调用 `hide()` 的恶性 Bug。
- **房间管理对话框 (`RoomManagerDialog`) 优化**：
  - 传入当前激活的界面名称，新建房间时默认归属当前界面。
  - 保存对话框变更时，通过唯一 `id` 精准更新或替换房间属性，杜绝跨界面房间被遗漏、覆盖或误设。

### 3. 设备图标完全包含于房间内部的底层逻辑修正 (`devicemonitorpanel.cpp`, `roomwidget.cpp`)
- **空间几何基准标准化**：
  - 卡片尺寸：宽 96px、高 106px（`CARD_W = 96, CARD_H = 106`）。
  - 房间预留边距：顶部 `PAD_TOP = 46px`（包含标题栏 22px + 设备计数徽标 16px + 边距），左 `PAD_LEFT = 16px`，右 `PAD_RIGHT = 16px`，底 `PAD_BOTTOM = 16px`，设备间距 `GAP_X = 16px, GAP_Y = 16px`。
- **房间容量自适应计算 (`ensureRoomCapacity`)**：
  - 根据房间内设备数量 $N$ 动态计算所需列数 $C$ 与行数 $R$，严格保证房间尺寸：
    $$W_{req} = PAD\_LEFT + PAD\_RIGHT + C \times CARD\_W + (C - 1) \times GAP\_X$$
    $$H_{req} = PAD\_TOP + PAD\_BOTTOM + R \times CARD\_H + (R - 1) \times GAP\_Y$$
  - 对于圆形或菱形房间，自动根据几何外接要求相应扩大宽高。
  - 若房间当前宽高小于 $W_{req}$ 或 $H_{req}$，自动扩容。
- **设备刚性边界约束 (`clampDevicesInsideRoom`)**：
  - 无论在设备拖拽（`onDeviceDragged`）、房间尺寸缩放（`onRoomResized`）、房间移动（`onRoomMoved`）还是配置加载时，对所有归属该房间的设备执行坐标钳位：
    $$X_{clamped} \in [r.geom.x() + PAD\_LEFT, \quad r.geom.right() - PAD\_RIGHT - CARD\_W]$$
    $$Y_{clamped} \in [r.geom.y() + PAD\_TOP, \quad r.geom.bottom() - PAD\_BOTTOM - CARD\_H]$$
  - 在 `RoomWidget::mouseMoveEvent` 调整尺寸时，设置动态最小缩放尺寸，禁止用户将房间缩放到小于内部设备总占用范围。
