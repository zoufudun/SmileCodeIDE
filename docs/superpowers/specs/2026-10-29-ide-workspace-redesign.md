# SmileCodeIDE 开发工作台重构设计

## 用户要求与范围

按截图清理混乱和无用图标；删除图 3 整条编辑器工具栏；补齐主 IDE 芯片、烧录、智能工具链配置；提供前进/后退、缩进、注释与 Doxygen 模板、定义/引用及跨文件查找。生成总结并本地 Git 提交，不推送远程，不操作外部目标板。

## 布局方案

推荐“精简开发工作台”：保留一条带清晰文字的顶部开发工具栏，项目/保存、编译/烧写/调试、配置三组入口；调试控制仅在会话中显示。图 3 编辑器工具栏删除，原来的工具应用、主题、分栏移至菜单。移除底部重复操作条，目标/探针以紧凑配置摘要展示。左侧项目树、中央编辑器、下方输出/问题/项目搜索，右侧调试停靠面板仅在调试时显示，允许从视图菜单主动打开。

备选一：调试面板常驻，其余相同，方便硬件重度用户但减少编辑空间。备选二：仅清理图标并保留旧布局，改动较小但无法解决截图中的重复控制与空间失衡。

## 配置与持久化

复用 TargetChipDialog、FlashConfigDialog、ToolchainConfigDialog。主 IDE 提供明确的三个独立入口。芯片/烧录选项写入工程 .smilecode/project.json；工具链为用户级设置，兼容旧 Toolchain 配置并以完整 STM32Toolchain 配置优先。烧录时传入全部已保存选项，包括驱动、序列号、速率、地址、校验/复位/擦除和自定义脚本，调试使用对应接口配置。保存配置不触发真实烧写。

工具链扫描覆盖现有探测器的 PATH、环境变量、常用目录、安装包目录与 GCC 配套工具；扫描和版本自检在后台线程进行。显示检测过程/结果，不覆盖用户已配置但暂未找到的工具；保存后应用到当前控制器。

## 编辑器命令

采用共享 QAction，放入编辑/导航/搜索菜单和右键菜单，快捷键不依赖已删除工具栏。保留现有定义/引用分析能力，明确其基于项目源码扫描的边界，不宣称完整语言服务器语义。

- Alt+Left/Right：跨文件导航历史，返回精确行列，新导航丢弃前进分支；打不开的路径给出反馈。
- Ctrl+]/Ctrl+[：选中行缩进/反缩进，选择结束于下一行第 0 列时不修改该行，单次撤销。
- Ctrl+/：切换行注释；Ctrl+Shift+/：块注释；提供 Doxygen 函数/文件注释模板和模板编辑入口，支持 brief、param、return、file、author、date 等占位符；函数参数从当前声明提取，无法识别时不虚构参数。
- F12：定义；Shift+F12：引用；Alt+O：头文件/源文件切换；Ctrl+Shift+F：项目查找。提供中文右键分组、撤销/重做、剪切/复制/粘贴、重命名、格式缩进等常用入口。

新增编辑器命令实现文件，避免继续扩大现有 codeeditor.cpp。跨文件查找采用独立面板与后台搜索器，支持文本/正则、大小写、全词，排除构建目录与 .git，不跟随外部符号链接，限制大文件与结果数量并显示边界；支持取消、结果双击跳转、当前未保存缓冲区内容。
