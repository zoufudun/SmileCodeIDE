# 串口调试利器 UI 增强及体验升级计划 (UI Enhancements)

根据您的最新需求，我制定了以下详尽的修复和重构计划，旨在从功能逻辑、界面美观度和操作效率上大幅提升您的开发调试体验：

## 1. 默认折叠接收/发送设置
- **目标**：界面更加专注，减少启动时初见面的繁杂感。
- **实施方案**：在 `SerialSession::setupUi` 的末尾，对 `m_dockRx` 和 `m_dockTx` 增加 [hide()](file:///m:/TOPFIRE/SmileCodeIDE/STM32IDE/serialportplot.cpp#1924-1938) 默认关闭操作。用户如有需要可以通过菜单或布局自动唤出。

## 2. 修复 “显示原始数据” 的逻辑失效
- **背景**：此前，开启 “显示原始数据” 会在底层意外触发阻止原始数据打印的负逻辑。
- **实施方案**：
    - 重构 `SerialSession::onReadyRead`：如果勾选“显示原始数据”，则不仅不屏蔽，还要将**最原汁原味的字节（包括 `$` 和 `;`）直接展示**。
    - 补充 [updateWaveform](file:///m:/TOPFIRE/SmileCodeIDE/STM32IDE/serialportplot.cpp#1476-1651)：反之，如果不勾选此项，则在示波器接收区仅展示**干净纯粹的 Payload 数据（滤除了协议头尾）**，以达成真正意义上对数据内容的精准剥离。

## 3. 示波器设置面板大融合与精细布局
- **背景/痛点**：“绘图设置” (Plot Settings) 和 “示波器设置” (Scope Settings) 被零散分布在了两个不同的停靠层里，找起来费劲。
- **实施方案**：
    - 完全移除独立的 `m_dockSettings`（绘图设置停靠窗）。
    - 将关于时间轴宽 (`m_spinPoints`)、Y轴锁定 (`m_spinYMin/Max/Tick`)、标尺缩放 (`m_btnAutoScale`) 和清除功能，有机融合到 `m_dockScopeSettings`（主面板左下角的示波器设置内部）。
    - 采用网格 (`QGridLayout`) 分区，让“显示控制区”、“参数阈值区”及“操作区”一目了然。

## 4. 彻底去除 “串口设置” 标题烂影（Shadow Glitch Fix）
- **背景**：由于全局某些 QSS（如扁平化 CardWidget 化）意外引入了边缘阴影错乱渲染，盖住了标头。
- **实施方案**：针对 `m_dockPort` 设置专属且扁平整洁的 StyleSheet（例如去除无用的内边框阴影或 TitleBar 背景穿透）。对 `QDockWidget::title` 指定透明的无边框边距，还标题清爽观感。

## 5. 填缝主题色：更加炫丽精美的深层渲染 (Premium Theme Fill)
- **背景**：普通灰白的容器缺少专业级调试器的质感。
- **实施方案**：为 `grpPort`（串口框）和 `grpScope`（示波器框）附着**浅淡色度、带微圆角及柔和光效**的主题渐变色。
    - 使用类似 `#F8FAFC` 到淡蓝色的高级色散（具体受主题限制），并配合 `border-left` 或强对比色块凸显板块属性。

## 6. 核心动作按键换装图标组件 (Icon Retouch)
- **实施方案**：使用强大的 `CIconFont` 对原生文字按钮进行升级：
    - 刷新按钮：更新为刷新图标 `\uE84D`
    - 打开串口：更新为运行/播放图标 `\uE84E`
    - 关闭串口：更新为暂停/停止图标 `\uE855`
