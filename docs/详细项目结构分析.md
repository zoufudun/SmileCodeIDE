### 磁盘缓存问题缓解（Windows）

- 将 `userData` 路径重定向到项目本地 `__dirname + '/.electron-cache'`，避免 `%APPDATA%` 权限冲突。
- 使用 `app.commandLine.appendSwitch('disable-gpu-cache')` 禁用 GPU 缓存，避免 "Gpu Cache Creation failed"。
- 使用 `app.commandLine.appendSwitch('disable-features', 'MoveCache')` 禁用磁盘缓存迁移，解决 Windows 上 `cache_util_win` 的"拒绝访问"错误。

### 4.1 WebSocket 通信模块

#### 连接管理

- **服务器 URL**: `ws://localhost:12345`

- `connect()` 函数

  :

  - 关闭旧连接，创建新 `WebSocket(wsUrl)`
  - `onopen`: 更新连接状态为 "已连接网关"，修改 `.connection-status` 类为 `.connected`，清除重连定时器
  - `onclose`: 更新状态为 "未连接 (重试中...)"，切换类为 `.disconnected`，隐藏设备网格和未摆放区，显示空状态，设置 3 秒自动重连定时器
  - `onerror`: 仅 `console.error`
  - `onmessage`: 见下方

#### 消息协议 -- 两种类型

##### (a) `config` 消息



```json
{
  "type": "config",
  "mappings": [
    {
      "deviceId": <number>,
      "deviceType": "detector" | "valve",
      "status": 0 | 1,
      "label": "<string>"
    },
    ...
  ]
}
```

- 处理: 保存 `latestMappings`，调用 `renderWorkspace()` 完全重绘

##### (b) `update` 消息



```json
{
  "type": "update",
  "deviceId": <number>,
  "deviceType": "detector" | "valve",
  "status": 0 | 1,
  "label": "<string>"
}
```

- 处理: 更新 `latestMappings` 中的状态，找到对应 DOM 卡片并更新 CSS 类和状态文字，触发 `checkRegionContainment()` 更新房间报警状态，在报警日志面板追加格式化日志条目

#### 消息翻译 (`translateRawMessage`)

将 JSON 报文转为中文自然语言：

- `config`: "⚙️ 网关配置已同步：成功加载了 N 个设备。"
- `detector` update: "📡 设备变化：烟温探测器 [label] (异常报警🚨/复位正常💚) 状态变更为: 报警/复位"
- `valve` update: "📡 设备变化：控制分配阀 [label] (开启🟢/关闭🟠) 状态变更为: 开启/关闭"

------

### 4.2 设备模型

#### 数据结构（基于 `latestMappings`）



```
{
  deviceId:   <number>,        // 唯一标识符
  deviceType: "detector" | "valve",  // 设备类别
  status:     0 | 1,           // 0=正常/关闭, 1=报警/开启
  label:      <string>         // 显示标签
}
```

- **Detector（探测器）**: 状态 0 = NORMAL (绿色), 状态 1 = ALARM (红色闪烁)
- **Valve（阀门）**: 状态 0 = CLOSED (琥珀色), 状态 1 = OPEN (绿色，阀体旋转 90 度)

#### 渲染 (`renderWorkspace`)

- 对所有设备遍历，每设备创建一个 `div.device-card`
- 卡片类名为 `device-card kind-{DETECTOR|VALVE} status-{0|1}`
- 卡片内包含: 设备 ID 徽章、SVG 图标容器、标签文本、状态文本

### 4.3 SVG 图标系统

#### `getDetectorSvg()`

一个 24x24 的探测器 SVG，包含：

- 雷达脉冲波纹环（`.svg-radar-pulse`）：报警状态下通过 CSS 实现 `svg-radar-wave` 缩放+淡出动画
- 外层屏蔽环、传感器格栅、内层传感器杯
- 中央状态 LED（`.svg-led`）：正常时绿色，报警时红色闪烁（`led-alert-flash` 动画）

#### `getValveSvg()`

一个 24x24 的阀门 SVG，包含：

- 管道通道、法兰
- 动画流体路径（`.svg-flow-path`）：开启时显示虚线流动效果（`fluid-flow` 动画），关闭时静态灰色
- 圆形阀体 + 旋转蝶板（`.svg-wheel`）：开启时旋转 90 度且变绿，关闭时回到 0 度且变红

### 4.5 拖拽系统

#### 拖拽实现 (`setupDraggable`)

- 设备卡片: 整个卡片可拖拽
- 房间盒子: 仅 `.room-header` 区域可拖拽
- **流程**: `mousedown` 记录起始位置 -> `mousemove` 计算偏移量并应用 -> `mouseup` 保存最终坐标
- **网格吸附**: 根据 `gridSnapSize`（1/5/10/20px）吸合坐标
- **边界约束**: 限制在画布 `(0, 0)` 到 `(canvasWidth - itemWidth, canvasHeight - itemHeight)` 内
- **跨容器拖拽**: 从 `#unplaced-container` 拖到 `#device-grid` 时自动移除并重新附加 DOM 节点

#### 房间缩放 (`setupResizable`)

- 4 方向 + SE 角共 5 个拖拽手柄
- 方向支持: `t`(上), `b`(下), `l`(左), `r`(右), `se`(右下角)
- 最小尺寸: 宽 150px, 高 100px
- 支持网格吸附对齐

### 4.6 房间系统

#### 房间区域碰撞检测 (`checkRegionContainment`)

- 计算每张卡片中心点 `(cx, cy)`
- 检测中心点落在哪个房间的矩形区域内
- 更新每个房间的 `room-badge` 显示设备计数
- 若房间内任一设备处于报警状态(status=1)，添加 `alarm-active` 类（触发红色闪烁边框效果）

- 设备卡片

void DeviceMonitorPanel::onNewConnection() {
    QWebSocket *client = m_wsServer->nextPendingConnection();
    connect(client, &QWebSocket::disconnected, this, &DeviceMonitorPanel::onClientDisconnected);
    m_clients.append(client);
    appendLog(QStringLiteral("[WebSocket] 客户端已连接：%1:%2")

## 3. JSON 消息格式

服务器向客户端发送两种类型的 JSON 消息：**`config`** 和 **`update`**。

### 3.1 `config` 类型消息 -- 完整设备映射配置

当新客户端连接时，或设备映射发生变化时（`rebuildGrid()` 被调用后），发送此消息。

**发送时机：**

1. 新客户端连接时（`onNewConnection` 第 355 行）
2. 设备映射重建时（`rebuildGrid` 第 303-306 行）

**发送函数 `sendConfigToClient()`**（第 309-337 行）：



```cpp
void DeviceMonitorPanel::sendConfigToClient(QWebSocket *client) {
    QJsonObject configObj;
    configObj[QStringLiteral("type")] = QStringLiteral("config");

    QJsonArray mappingsArr;
    for (const auto &mapping : m_mappings) {
        QJsonObject item;
        item[QStringLiteral("deviceId")] = mapping.deviceId;
        item[QStringLiteral("label")] = mapping.label;
        item[QStringLiteral("deviceType")] = mapping.deviceType;
        item[QStringLiteral("canId")] = static_cast<int>(mapping.canId);
        item[QStringLiteral("byteIndex")] = mapping.byteIndex;
        item[QStringLiteral("bitIndex")] = mapping.bitIndex;

        // 获取当前状态
        bool currentStatus = false;
        auto *widget = m_deviceWidgets.value(mapping.deviceId, nullptr);
        if (widget) {
            currentStatus = widget->status();
        }
        item[QStringLiteral("status")] = currentStatus;

        mappingsArr.append(item);
    }
    configObj[QStringLiteral("mappings")] = mappingsArr;

    QJsonDocument doc(configObj);
    client->sendTextMessage(QString::fromUtf8(doc.toJson(QJsonDocument::Compact)));
}
```

**config 消息 JSON 结构：**



```json
{
  "type": "config",
  "mappings": [
    {
      "deviceId": 1,
      "label": "设备名称",
      "deviceType": "detector",
      "canId": 256,
      "byteIndex": 0,
      "bitIndex": 0,
      "status": false
    }
  ]
}
```

| 字段                    | 类型   | 说明                                            |
| ----------------------- | ------ | ----------------------------------------------- |
| `type`                  | string | 固定为 `"config"`                               |
| `mappings`              | array  | 设备映射数组                                    |
| `mappings[].deviceId`   | int    | 设备唯一标识符                                  |
| `mappings[].label`      | string | 显示名称                                        |
| `mappings[].deviceType` | string | `"detector"`（探测器）或 `"valve"`（阀门）      |
| `mappings[].canId`      | int    | CAN 帧 ID（十进制，如 256 即 0x100）            |
| `mappings[].byteIndex`  | int    | 数据字节索引，范围 0-7                          |
| `mappings[].bitIndex`   | int    | 位索引，范围 0-7（LSB=0）                       |
| `mappings[].status`     | bool   | 当前设备状态（true=报警/开启，false=正常/关闭） |

### 3.2 `update` 类型消息 -- 实时状态更新

当 CAN 帧到达且设备状态发生变化时，广播给所有连接的客户端。

**构建代码**（第 253-261 行）：



```cpp
QJsonObject updateObj;
updateObj[QStringLiteral("type")] = QStringLiteral("update");
updateObj[QStringLiteral("deviceId")] = mapping.deviceId;
updateObj[QStringLiteral("status")] = bitVal;
updateObj[QStringLiteral("prevStatus")] = prev;
updateObj[QStringLiteral("label")] = mapping.label;
updateObj[QStringLiteral("deviceType")] = mapping.deviceType;
updateObj[QStringLiteral("timestamp")] = QDateTime::currentDateTime().toString("yyyy-MM-dd HH:mm:ss");

```

**update 消息 JSON 结构：**



```json
{
  "type": "update",
  "deviceId": 1,
  "status": true,
  "prevStatus": false,
  "label": "设备名称",
  "deviceType": "detector",
  "timestamp": "2026-07-19 14:30:25"
}
```

| 字段         | 类型   | 说明                                                         |
| ------------ | ------ | ------------------------------------------------------------ |
| `type`       | string | 固定为 `"update"`                                            |
| `deviceId`   | int    | 设备唯一标识符                                               |
| `status`     | bool   | 新状态（true=报警/开启，false=正常/关闭）                    |
| `prevStatus` | bool   | 前一个状态                                                   |
| `label`      | string | 设备显示名称                                                 |
| `deviceType` | string | `"detector"` 或 `"valve"`（根据类型，日志中显示不同的方向提示词） |
| `timestamp`  | string | 格式为 `"yyyy-MM-dd HH:mm:ss"` 的时间戳                      |

### 3.3 广播机制

`broadcastMessage()` 方法（第 339-345 行）：



```cpp
void DeviceMonitorPanel::broadcastMessage(const QJsonObject &json) {
    QJsonDocument doc(json);
    QString msg = QString::fromUtf8(doc.toJson(QJsonDocument::Compact));
    for (auto *client : m_clients) {
        client->sendTextMessage(msg);
    }
}
```

对所有当前连接的客户端发送紧凑格式（无空格、无换行）的 JSON 文本消息。

## 5. 数据流与状态更新流程总结



```
CAN 硬件
  |
  v
CanInterface::frameReceived 信号
  |
  v
DeviceMonitorPanel::onFrameReceived(const CanFrame &frame)
  |
  |-- 遍历 m_mappings，匹配 frame.id == mapping.canId
  |-- 提取 frame.data[byteIndex] 中的 bitIndex 位
  |-- 更新 DeviceStatusWidget 的 UI 状态
  |-- 如果状态发生变化（bitVal != prev）：
  |     |-- 记录日志
  |     |-- 构建 update 类型 JSON
  |     |-- broadcastMessage() --> 发送给所有 WebSocket 客户端
  |
  |-- 如果 rebuildGrid() 被调用（配置变化）：
        |-- 遍历所有客户端
        |-- sendConfigToClient(client) --> 发送 config 类型 JSON

新客户端连接：
  onNewConnection()
    |-- sendConfigToClient(client) --> 立即发送完整配置
```
