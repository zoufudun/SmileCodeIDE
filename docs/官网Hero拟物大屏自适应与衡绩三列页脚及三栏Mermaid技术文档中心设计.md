# 官网 Hero 拟物大屏自适应与衡绩三列页脚及三栏 Mermaid 技术文档中心设计

## 1. 概述与需求背景

为了进一步提升 **SmileCode Studio (微笑代码工作站)** 官方网站的高端视觉品质与专业开发者体验，针对用户提出的以下核心演进要求进行了系统性设计与重构：
1. **Hero 拟物展示加大与全局色彩一致性（图 1 优化）**：
   - 现有的 Hero 区域右侧模拟窗口尺寸偏小，需要在大屏幕下自适应扩展加大，赋予工作台更加从容大气的视觉张力；
   - 消除暖羊皮纸浅色模式下右侧窗口依然为生硬黑色的色彩割裂感，实现窗口底壳、标题栏、侧边栏、卡片与边框随主题（暗夜钛金与暖羊皮纸）无缝自适应联动。
2. **导航栏精简与层次聚焦（图 2 优化）**：
   - 将原顶部导航栏的“`产品套件 (9大插件) ▾`”精简为更加利落专业的“`产品 ▾`”。
3. **现代三列式品牌页脚重构（图 3 改为图 4 衡绩风格）**：
   - 彻底废弃原本单薄紧缩的单行页脚；
   - 100% 对标图 4（衡绩 HengJi 官方网站）的高端布局：左列为品牌定位与团队联系方式，中列为快速入口垂直导航，右列为开源资源与下载矩阵，底部配备细线版权栏。
4. **全功能三栏式 Markdown 与 Mermaid 技术文档中心（图 5 对齐）**：
   - 建立全新的独立文档页面 `website/docs.html`，并在全局导航栏新增【文档】入口；
   - 采用经典现代的三栏式流式响应布局：
     - **左侧边栏**：分类可折叠的文档树导航，顶部搭载实时模糊搜索框（`Ctrl+K`）；
     - **中间主内容区**：严格遵循 Markdown 规范撰写，段落层次分明、配备精美对比表格与 Callout 提示框，且**全篇技术图表全部采用 Mermaid 语法实时渲染为矢量图**；
     - **右侧边栏**：动态抓取正文各级章节标题（`On This Page`），支持平滑滚动（Smooth Scroll）与视口滚动监听高亮（ScrollSpy），实现毫秒级快速定位。

## 2. 根本原因定位与架构分析

### 2.1 Hero 拟物窗口双主题割裂根因
- 原先的 `website/studio-simulator.css` 中，`.studio-real-chassis` 及其内部控件的背景色与文字色大量采用硬编码的深灰/纯黑 HEX 值（如 `#11141c`、`#141720`），没有针对 `body[data-theme="parchment"]` 提供对应的 CSS 选择器覆盖规则；
- 导致整站切换为柔和温润的米色暖羊皮纸时，右侧仿真窗口仍维持纯黑形态，在页面上显得非常突兀。

### 2.2 原页脚结构单一与信息密度不足根因
- 原 `index.html` 的 Footer 采用单一的 `flex: space-between` 结构，无法承载丰富的平台导航、开源生态与团队技术支持信息，缺乏成熟商业软件的稳重感。

### 2.3 技术文档与矢量图表展示规范
- 传统以纯截图呈现技术架构的方式存在清晰度低、放大模糊、无法复制代码、且在明暗主题切换时背景无法融合的致命缺陷；
- 引入 **Mermaid.js** 矢量渲染引擎，能够将文本形式的 UML/流程图动态编译为 SVG 矢量图，并与页面的暗黑钛金/暖羊皮纸调色板实时双向适配。

## 3. 具体修改措施与实现代码

### 3.1 导航栏与 Hero 区域加大自适应
1. **导航栏精简**：
   在 [`website/index.html`](file:///k:/TOPFIRE/SmileCodeIDEUpdate/website/index.html) 以及全部 9 个插件页面中，将导航栏的按钮文案由“`产品套件 (9大插件)`”统一修改为“`产品`”，并注入“`文档`”导航链接。
2. **Hero 栅格比例扩容**：
   - 将 `.hero-section .container` 的最大宽度从 `1280px` 扩展至 `1480px`；
   - 将左右栅格比例调整为 `1fr 1.5fr`，使右侧工作台宽度扩展至 `820px ~ 920px`；
   - 将 `.studio-workspace` 高度限制扩展至 `520px ~ 600px`，让 9 大应用卡片展现出更宏大的空间感。

### 3.2 拟物工作台暖羊皮纸主题深度自适应
在 [`website/studio-simulator.css`](file:///k:/TOPFIRE/SmileCodeIDEUpdate/website/studio-simulator.css) 中，全面注入 `[data-theme="parchment"]` 专有样式：
- 外壳底色：`#fdfaf2`，边框 `#dfd6c5`，柔和米褐立体投影；
- 标题栏：`#eee6d8`，深棕色文字 `#3d3630`；
- Header 与搜索框：纯白底色搭配细微暖边框，陶土橙高亮聚焦态；
- 侧边栏：`#f3ece0`，选中的分类项采用高饱和陶土橙高亮 `#c2410c`，字体纯白挺拔；
- 应用卡片：纯白背景 `#ffffff`，暖灰边框 `#e6ddd0`，悬浮时触发琥珀金微光与平滑上浮效果；
- 状态栏：`#eee6d8`，深灰沉稳文字。

### 3.3 图 4 衡绩风格三列式现代页脚实现
在 [`website/style.css`](file:///k:/TOPFIRE/SmileCodeIDEUpdate/website/style.css) 与 HTML 模板中引入三列式栅格：
- **左列（品牌与使命）**：Logo 徽章、主标题“SmileCode Studio · 微笑代码工作站”、一句话定位以及研发团队联系邮箱；
- **中列（快速入口）**：工作台体验、9 大插件矩阵、优化等级配置、安装包下载矩阵、技术文档中心；
- **右列（开源与资源）**：GitHub 源码仓库、Releases 历史包、版本更新日志、插件 SDK、Issue 提交；
- **底部细线**：版权声明与回到顶部快捷链接；
- **双主题支持**：暗色模式采用碳纤黑 `#161a22`，暖羊皮纸模式采用温和米褐 `#ede6d6`（与图 4 100% 吻合）。

### 3.4 全新三栏式技术文档中心 (`website/docs.html`)
基于图 5 的设计规范独立开发 [`website/docs.html`](file:///k:/TOPFIRE/SmileCodeIDEUpdate/website/docs.html)：
1. **左侧目录导航**：
   - 顶部提供实时搜索框，带快捷键 `Ctrl+K`；
   - 6 大手风琴分组：SmileCode 平台与上手、总线与通信调试、测量分析与虚拟仪器、固件升级与烧录、底层攻坚白皮书、跨平台打包与插件扩展。
2. **中间 Markdown 正文区与 5 大 Mermaid 矢量图表**：
   - **图 1：分层解耦系统架构全景**（Mermaid `flowchart TD`）
   - **图 2：STM32 增量编译、自动化烧录与 GDB 在线调试闭环时序**（Mermaid `sequenceDiagram`）
   - **图 3：GCC 编译器优化等级对软件延时与硬件外设状态的影响机理**（Mermaid `flowchart LR`）
   - **图 4：STM32 IAP 固件升级协议双向握手状态机**（Mermaid `stateDiagram-v2`）
   - **图 5：标准 Qt Plugin 生命周期、事件驱动与宿主交互架构**（Mermaid `flowchart TD`）
3. **右侧 On This Page 章节快速定位导航**：
   - 自动列出当前文档的各级小节；
   - 原生 `IntersectionObserver` 监听阅读视口，实时高亮当前章节；
   - 点击支持平滑滚动直达锚点。
4. **Mermaid 矢量图与双主题协同**：
   - 引入 Mermaid.js 官方稳定引擎；
   - 动态判定主题：暗黑模式下启用 `dark` 主题，暖羊皮纸下启用 `neutral` 优雅大地色系主题。
